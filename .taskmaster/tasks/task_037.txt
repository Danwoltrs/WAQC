# Details:
PROBLEM ANALYSIS:
The error code 42501 "new row violates row-level security policy for table samples" occurs when lab assistants attempt to create samples through POST /api/samples. The current RLS INSERT policy in database/migrations/010_comprehensive_rls_policies.sql (lines 78-82) only permits these roles: 'lab_personnel', 'lab_quality_manager', 'global_quality_admin', 'global_admin'. However, the user_role ENUM (001_initial_schema.sql:10-20) includes 'lab_assistant' as a distinct role not covered by the current policy.

ROOT CAUSE:
The INSERT policy uses get_user_qc_role() which checks profiles.qc_role against a hardcoded list that excludes 'lab_assistant'. Migration 098_fix_rls_array_comparison_issue.sql updated the UPDATE policy to avoid array comparisons but only fixed updates, not inserts.

IMPLEMENTATION STEPS:

1. Create new migration file: database/migrations/106_fix_lab_assistant_sample_insert.sql

2. Include comprehensive fix addressing both INSERT and any remaining role checks:

```sql
-- Migration 106: Fix RLS policy to allow lab_assistant to create samples
-- Date: 2025-11-25
-- Purpose: Add lab_assistant role to sample INSERT policy to resolve error 42501

-- Drop existing INSERT policy
DROP POLICY IF EXISTS "Lab personnel can insert samples" ON samples;

-- Create updated INSERT policy that includes lab_assistant
CREATE POLICY "Lab personnel can insert samples" ON samples
    FOR INSERT
    WITH CHECK (
        -- Service role bypasses all checks
        auth.jwt() ->> 'role' = 'service_role'
        OR
        -- Lab personnel in the same lab (including lab_assistant)
        (
            laboratory_id = get_user_qc_laboratory(auth.uid())
            AND
            (
                get_user_qc_role(auth.uid()) = 'lab_assistant' OR
                get_user_qc_role(auth.uid()) = 'lab_personnel' OR
                get_user_qc_role(auth.uid()) = 'lab_quality_manager' OR
                get_user_qc_role(auth.uid()) = 'global_quality_admin' OR
                get_user_qc_role(auth.uid()) = 'global_admin'
            )
        )
    );

COMMENT ON POLICY "Lab personnel can insert samples" ON samples IS
'Allows service role and all lab personnel (including lab_assistant) to create samples in their assigned laboratory. Avoids IN operator to prevent array comparison errors.';

-- Verification query

```
